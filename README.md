# ویتامین‌نامه — پلتفرم علمی فارسی ویتامین‌ها

وب‌اپلیکیشن فارسی برای مطالعه، تحلیل و محاسبه دریافت ویتامین‌ها، مبتنی بر منابع معتبر (NASEM، EFSA، NIH ODS، USDA FoodData Central، WHO).

## امکانات نسخه فعلی

| بخش | مسیر | توضیح |
|---|---|---|
| خانه | `/` | خط‌کش تعاملی EAR، RDA و UL |
| دانشنامه | `/vitamins` و `/vitamins/:slug` | ۱۳ پرونده علمی با ۱۲ بخش، جدول کامل ۲۲ گروه سنی، مقایسه EFSA، سطح شواهد، منابع |
| ماشین‌حساب دریافت | `/calculator` | غذا + مکمل (روزانه، هفتگی، ماهانه)، تبدیل واحد، احتمال کفایت (IOM 2000)، UL با دامنه صحیح |
| ارزیابی آموزشی | `/assessment` | عوامل خطر، علائم، داروها، آزمایش‌ها و سطح ارجاع؛ بدون تشخیص |
| تداخلات | `/interactions` | ۲۸ تداخل دارویی، آزمایشگاهی و مغذی با منبع |
| منابع غذایی و مقایسه | `/foods`، `/compare`، `/standards` | جدول قابل مرتب‌سازی، رتبه‌بندی منابع، آمریکا در برابر اروپا |
| آموزش | `/learn` | مقالات مفاهیم پایه |
| پنل تخصصی | `/pro` | پرونده مراجع با رضایت آگاهانه و بازبینی علمی محتوا (ذخیره محلی) |
| گزارش پژوهشی | `/research` | بررسی سامانه‌های مشابه، شکاف‌ها، معماری، نقشه راه |

جست‌وجوی سراسری: <kbd>Ctrl</kbd>+<kbd>K</kbd> یا <kbd>/</kbd>

## اجرای محلی

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # آزمون‌های موتور محاسبه و یکپارچگی داده
npm run build      # خروجی در dist/
```

نیازمند Node.js نسخه ۱۸ یا بالاتر.

## استقرار روی Vercel

**روش ۱ — از طریق GitHub (پیشنهادی):**

1. یک مخزن جدید در GitHub بسازید و این پوشه را push کنید:
   ```bash
   git init && git add . && git commit -m "ویتامین‌نامه نسخه ۱"
   git branch -M main
   git remote add origin https://github.com/<USERNAME>/vitamin-platform.git
   git push -u origin main
   ```
2. در [vercel.com/new](https://vercel.com/new) مخزن را Import کنید.
3. Vercel تنظیمات را از `vercel.json` می‌خواند (Framework: Vite، Build: `npm run build`، Output: `dist`). روی Deploy بزنید.
4. هر push بعدی به‌طور خودکار منتشر می‌شود و هر Pull Request یک نشانی پیش‌نمایش می‌گیرد.

**روش ۲ — از خط فرمان:**

```bash
npm i -g vercel
vercel          # پیش‌نمایش
vercel --prod   # انتشار نهایی
```

> پلن رایگان Hobby در Vercel فقط برای استفاده شخصی و غیرتجاری است؛ برای استفاده تجاری پلن Pro لازم است.

### میزبان‌های دیگر

خروجی `dist/` کاملاً ایستاست و روی هر میزبان (از جمله میزبان‌های داخلی) قابل استقرار است. اگر میزبان امکان rewrite همه مسیرها به `index.html` را ندارد، با مسیریابی hash بسازید:

```bash
VITE_ROUTER=hash npm run build
```

## ساختار پروژه

```
src/
  data/        داده‌های علمی نسخه‌دار (DRI، EFSA، پرونده‌ها، غذاها، تداخلات، مقالات، گزارش)
  engine/      موتور محاسبه خالص و آزمون‌پذیر (گروه مرجع، واحدها، دریافت، غربالگری)
  components/  اجزای رابط (خط‌کش دریافت، جست‌وجو، پوسته)
  pages/       صفحات
scripts/
  import-fdc.mjs   واردسازی و تطبیق داده غذاها با USDA FoodData Central
docs/
  DEVELOPMENT.md   مراحل توسعه، تصمیم‌ها و گام‌های بعدی
```

## افزودن یا ویرایش داده علمی

- مقادیر مرجع: `src/data/dri.ts` (ترتیب ستون‌ها در توضیح تابع `row` آمده است).
- پرونده ویتامین‌ها: `src/data/vitamins-fat.ts` و `src/data/vitamins-water.ts`.
- غذاها: `src/data/foods.ts` — داده خالی یعنی «موجود نیست» و با صفر فرق دارد.
- پس از هر تغییر `npm test` را اجرا کنید؛ آزمون‌ها ناسازگاری‌هایی مثل EAR بزرگ‌تر از RDA را پیدا می‌کنند.

تطبیق غذاها با FoodData Central:

```bash
FDC_API_KEY=<کلید رایگان شما> npm run import:fdc -- --compare
```
